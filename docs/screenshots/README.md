# Screenshot provenance

These PNG files are captures of the running Little Reader application in local demo mode. They contain only original example stories and vector artwork generated by `scripts/make_fixture.py` and `scripts/prepare_demo.py` under the project's Apache-2.0 license.

No commercial PDF, commercial cover, copyrighted book page, real account, user recording, address bar, credential, private filename or production domain was used. Local demo books are marked as test examples; they are intentionally excluded from real-library completion statistics.

Captured with Playwright / installed Chrome at 1365×900 (desktop) and 390×844 (mobile). Mobile emulation is a layout check, not a physical-device or WeChat certification.

Regenerate deliberately:

```bash
PW_CHANNEL=chrome SCREENSHOT_DIR=docs/screenshots npm run test:e2e
```

Browser plugin not available during initial preparation; regular Playwright was used. The suite checks the real bookshelf, search, page navigation, saved position and picker state and rejects application console errors. It does not mock book pages or invent scoring results.
